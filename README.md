# Colvenna website

This repository holds the Colvenna series website: the generated static pages (`index.html`, `site.js`, `styles.css`) and the brand assets. GitHub Pages publishes it from the root of `main`, at the domain in `CNAME`.

The site files are generated by the series index's site build and copied here in a pull request. A sync replaces the site files only. It keeps this README, `.gitguardian.yaml`, `.pre-commit-config.yaml`, `scripts/` and `.github/`.

## Secret scanning

Nothing is made public before [ggshield](https://docs.gitguardian.com/ggshield-docs/getting-started), GitGuardian's command-line scanner, finds 0 incidents in it with this repository's [`.gitguardian.yaml`](.gitguardian.yaml).

- **Each change:** a change is published once it is merged into `main`, so its pull request first passes the [secret scan workflow](.github/workflows/secret-scan.yml). The workflow scans the new commits of each push and pull request with the `GITGUARDIAN_API_KEY` Actions secret. A manual run of it scans the whole history.
  - Pull requests from forks get no secrets, so for them the job only notes this. A maintainer scans such a change before merging it.
- **The full scan:** a maintainer runs [`scripts/secret-scan.sh`](scripts/secret-scan.sh) after each site sync and records its summary in the sync's pull request:

  ```bash
  python3 -m venv /tmp/colvenna-ggshield
  /tmp/colvenna-ggshield/bin/python -m pip install --require-hashes --only-binary=:all: \
    -r scripts/secret-scan-requirements.lock
  GITGUARDIAN_API_KEY=... GGSHIELD=/tmp/colvenna-ggshield/bin/ggshield scripts/secret-scan.sh <private directory>
  ```

  It scans an anonymous mirror clone (every branch, tag and `refs/pull/*`) and each pull-request head that a force push replaced and GitHub still serves. It uses the `.gitguardian.yaml` of `main` (a second argument selects another branch), and exits 0 only when the scan is clean. The website is the repository's content, so the history covers it.
  - The report in the directory contains the matched values, so keep the directory private.
  - The printed summary has no values.
- **Each commit:** `pre-commit install` enables the [ggshield hook](.pre-commit-config.yaml), which scans the staged changes.
  - It needs a GitGuardian API key: `GITGUARDIAN_API_KEY`, or `ggshield auth login`.
  - Without one, it stops with ggshield's error. `SKIP=ggshield git commit ...` skips it, but the CI job still applies.
- **A finding:**
  - A real credential is revoked or rotated first, then the history is reviewed. It is never ignored.
  - Any other finding is added to `.gitguardian.yaml` by its ignore SHA, with a name that gives the file and the reason. The addition is reviewed in its pull request.
  - No path or detector is ignored.
